6. Attack Resistance Matrix

Stole .env File

Tokens encrypted with master key. Need master key to decrypt and use.

Stole operators.json

Passwords encrypted with AES-256-GCM. HMAC signature detects tampering.

Stole GitHub Backup

All data encrypted. encrypted_password fields need master key to decrypt.

Brute Force Login

Rate limited: 5 attempts per 15 min. 30-minute lockout after threshold.

Stolen Session Token

Invalidated on password change via token_version increment.

Tampered Data

HMAC-SHA256 signature on operators.json. Integrity check on load.

Timing Attack

All password comparisons use crypto.timingSafeEqual.

Container Compromise

Bootstrap key derived from runtime machine data, never stored on disk.
